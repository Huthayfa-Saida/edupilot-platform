# School SaaS Project

هذا هو المجلد الأساسي لمشروع نظام إدارة المدارس ورياض الأطفال (SaaS).

## الهيكل الحالي

- apps/api: تطبيق الـ Backend
- apps/web: تطبيق الـ Frontend
- packages/shared: كود مشترك بين التطبيقات
- docs: وثائق المشروع
- docker: إعدادات Docker

## المرحلة الحالية

نركز الآن على:

1. تسجيل الأطفال
2. إدارة الرسوم والدفع اليدوي
3. إدارة أولياء الأمور
4. تصميم Master DB و Tenant Routing

## الملاحظات

- كل مدرسة لها قاعدة بيانات منفصلة (DB per tenant)
- يتم تحديد المدرسة عبر subdomain
- التطبيق الأساسي يكون واحدًا، مع اتصال قاعدة بيانات ديناميكي حسب المدرسة
