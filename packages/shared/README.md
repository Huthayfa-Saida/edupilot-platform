# Shared Package

## الهدف

هذا المجلد مخصص للمكتبات والمكونات المشتركة بين apps/api و apps/web.

## المحتوى المتوقع
- Types
- Constants
- Validation schemas
- Shared utilities
- Common enums and DTO structures

## المرحلة الحالية

هذا القسم جاهز للتعريف فقط، مع الحفاظ على هيكل المشروع منظمًا قبل بدء التنفيذ.
