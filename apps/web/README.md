# Web App

## الهدف

هذا المجلد مخصص لواجهة الإدارة الخاصة بالمشروع.

## المحتوى المتوقع
- React + TypeScript frontend
- Dashboard للإدارة
- صفحات تسجيل الأطفال والرسوم
- صفحة تسجيل الدخول واللوحة الرئيسية

## المرحلة الحالية

يتم فقط تجهيز هيكل المشروع وتوزيع العمل داخل الفريق، قبل الشروع في التطوير الفعلي.
