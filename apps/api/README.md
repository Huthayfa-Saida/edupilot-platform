# API App

## الهدف

هذا المجلد مخصص لتطبيق Backend الرئيسي للمشروع.

## المحتوى المتوقع
- NestJS / Express-based backend
- Tenant routing
- Master DB and school DB logic
- Authentication and authorization
- Modules: children, guardians, fees, payments

## المرحلة الحالية

المرحلة الحالية تركز على تصميم الهيكل والتنظيم فقط، وليس على التنفيذ البرمجي الفعلي.
